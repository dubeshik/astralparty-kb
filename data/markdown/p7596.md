## 活动奖励

切换进度 玩家可以通过完成活动任务获得![UT Item Activity 1000062](../images/1212f0713939.webp)假日星券。玩家每次可以通过消耗1个![UT Item Activity 1000062](../images/1212f0713939.webp)假日星券，选择开启九宫格中的任一图格并获取对应奖励，每当玩家获得单行（或单列、对角）的全部奖励后，则会获得该行（或列、对角）的额外奖励，具体奖励见右侧。 
玩家每完成1张翻牌，则会获取该进度的对应奖励，依照顺序排列如下：

| 翻牌进度 | 完成奖励 |
| --- | --- |
| 1 | ×1000 |
| 2 | ×10 |
| 3 | ×10 |
| 4 | ×1 |
| 5 | ×200 |
| 6 | ×5 |
| 7 | ×1 |

活动结束后，每个![UT Item Activity 1000062](../images/1212f0713939.webp)假日星券会转换为1个![UT Item Currency 1](../images/b79cdbfcaff0.webp)星币。
