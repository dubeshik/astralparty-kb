这个知识库怎么用

数据来自官方 BWiki（wiki.biligame.com/starengine），本地离线，只收游戏内容页。

看

左边按分类或搜索选词条。角色页是「一站式档案」：概览、皮肤（含默认与羁绊，全套数）、 表情、装扮、档案、语音，六个分页切换，不再把几十张图堆在页面底部。

喂给 AI

点「复制当前页」或「复制检索结果」，得到干净 Markdown（含本地图片链接与来源）。 也可以让 AI 直接读文件：

# 关键词检索（AND）
python tools/kb_search.py "芬妮 皮肤" --limit 5
# 结构化输出
python tools/kb_search.py "清凉盛夏" --json
# 整页 Markdown
python tools/kb_search.py "芬妮" --full
# 角色/皮肤/表情的结构化数据
python tools/kb_search.py --characters

数据文件

路径用途
data/markdown/每页一份 AI 友好 Markdown
data/chunks.jsonlRAG 分块（带章节路径）
data/characters.json角色 / 皮肤 / 表情结构化数据
data/images/本地图片（按原始文件名归并去重）

更新

python tools/fetch_wiki.py       # 增量抓取
python tools/download_images.py  # 下载新图
python tools/upgrade_images.py   # 缩略图升级原图
python tools/build_kb.py         # 重建全部产物

wiki 页面结构变化后可能需要调整 tools/extract.py 的解析规则。
